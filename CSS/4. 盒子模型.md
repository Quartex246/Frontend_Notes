如图所示，页面可以被看作一个盒子一样的模型。这个模型包含以下四条内容：

| 组成               | 含义                                                             |
| ---------------- | -------------------------------------------------------------- |
| **Content（内容区）** | 盒子最里层，**用来放实际内容（文字、图片等）**。图中标注的 `Width` / `Height` 指的就是内容区的宽高。 |
| **Padding（内边距）** | 内容区与边框之间的空白，让内容不至于贴着边框。它在盒子内部，盒子的背景色会延伸到这里。                    |
| **Border（边框）**   | 包住内容和内边距的边框线，可以设置粗细、样式和颜色。                                     |
| **Margin（外边距）**  | 盒子最外层的空白，用来把当前盒子与其他元素隔开。它在边框之外，盒子的背景色不会延伸到这里。                  |

从内到外依次是：**Content → Padding → Border → Margin**

如果要一个说人话版本的，那就是

content: 文本内容；
border：文本内容周围的一圈边框
padding：文本内容到边框的距离
margin：元素与元素间的距离
