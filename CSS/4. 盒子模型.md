
我超，盒子！

![[BoxModel.png]]

如图所示，页面中的每个元素都可以被看作一个“盒子”，这就是**盒子模型（Box Model）**。它从内到外分为四层：

| 组成 | 对应属性 | 含义 |
| --- | --- | --- |
| `Content`（内容） | `width` / `height` | 盒子最里层，用来放实际内容（文字、图片等）。图中标注的 `Width` / `Height` 指的就是内容区的宽高。 |
| `Padding`（内边距） | `padding` | 内容区到边框之间的距离，让内容不至于贴着边框。它在盒子内部，盒子的背景色会延伸到这一层。 |
| `Border`（边框） | `border` | 包住内容和内边距的边框线，可以设置粗细、样式和颜色。 |
| `Margin`（外边距） | `margin` | 边框外的一圈空白，用来把当前盒子与其他元素隔开。它在边框之外，盒子的背景色不会延伸到这里。 |

从内到外依次是：**`Content` → `Padding` → `Border` → `Margin`**。

说人话就是


- `content`：文本内容；
- `border`：文本内容周围的一圈边框；
- `padding`：文本内容到边框的距离；
- `margin`：元素与元素之间的距离。

其中 `padding`、`border`、`margin` 都是**复合（简写）属性**，可以一次给多个方向设值。

## 实际效果

渲染效果与图中一致：

- 给盒子设置背景色（如草绿色）时，`padding` 区域也会被染色，说明它属于盒子内部。表现形式大概就是文本背后会被打上颜色；
- 给 `border` 设成黑色时，能看到 `padding` 外面围着一圈黑线，说明 `border` 包在 `padding` 之外。

## `border` 的组成

`border` 是由 `border-style`（样式）、`border-width`（粗细）、`border-color`（颜色）合并成的简写属性，所以可以一次性写在 `border` 后面：

```css
border: 1px solid #333; /* 依次是：粗细 样式 颜色 */
```

## 值的数量规则

对 `padding`、`margin`、`border-width` 这类能作用于四个方向的属性：

- **1 个值**：上下左右同时生效，例如 `margin: 10px;`
- **2 个值**：依次对应 上下 / 左右，例如 `margin: 10px 20px;`
- **3 个值**：依次对应 上 / 左右 / 下，例如 `margin: 10px 20px 30px;`
- **4 个值**：按**上 → 右 → 下 → 左**顺时针，例如 `margin: 10px 20px 30px 40px;`

## 单独控制某一边

只想改某一条边时，用带方向的属性即可：

```css
border-top: 2px solid red;   /* 只有上边框 */
padding-left: 8px;           /* 只有左内边距 */
margin-bottom: 12px;         /* 只有下外边距 */
```

## 尺寸怎么算（补充）

默认情况下，`width` / `height` **只计算内容区**，不包含 `padding` 和 `border`，所以加上内边距和边框会把盒子撑大。若希望宽高直接包含内边距和边框、布局时更好算，可以设置：

```css
.box {
	box-sizing: border-box;
}
```
