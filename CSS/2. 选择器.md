

选择器是CSS中的关键部分，他可以针对特定的一个或一组元素应用样式

## 元素选择器

出现在head中，属于标签`<style>`下
元素选择器只对特定元素起到作用

e.g.
```html
<style>
	h1 {
		color = red;
	}
</style>

<body>
	<h1>header 1</h1>
</body>
```

## 类选择器

部分元素可以属于特定的类，对于这些有特定类的元素可以使用类选择器来应用样式
和元素选择器一样，出现在head中，属于标签`<style>`

e.g
```html
<style>
	.highlight {
		color = red;
	}
</style>

<body>
	<h1 class = "highlight">header 1</h1>
</body>
```
由例子可以看出，类选择器将只会对有对应属性的元素生效
## id选择器

部分元素也有特定的id，对于这些有特定id的元素可以使用类选择器来应用样式
和元素选择器一样，出现在head中，属于标签`<style>`

e.g
```html
<style>
	#header {
		color = red;
	}
</style>

<body>
	<h1 id = "header">header 1</h1>
</body>
```
由例子可以看出，类选择器将只会对有对应id的元素生效

## 通用选择器

对所有元素都适用
相比于前面的选择器，通用选择器只需要一个星号
```html
<style>
	* {
		font-family = TimesNewRoman;
	}
</style>
```

## 子元素选择器

元素之间亦有父子关系，先来看父子关系是怎么写的

```html
<div class = "dad">
	<p class = "son"> hi dad </p>
</div>
```

顾名思义，就是只对子元素生效
```html
<style>
.father > .son {
	color = red;
}
</style>
```
## 后代选择器（包含选择器）

先说明白一个点：子代和后代是不一样的。子代是父元素直接联系，而后代与父元素没有直接关系，只有包含关系

```html
<div class = "dad">
	<p class = "son"> hi dad </p>
	<div>
		<p class = "grandson">hi poppop</p>
	</div>
</div>
```

示例中的 `grandson` 类属于 `son` 类，**是 `son` 的子代，`father` 的后代**。如果我要用子代选择器的语法，那么所影响的样式将只影响 `son`，而不会影响到 `grandson`。 

因此，如果我们希望能用一个能够覆盖所有 `father` 包含的元素，就要用到后代选择器。

e.g
```html
<style>
.father p {
	color = red;
}
</style>
```

相比于子代选择器有明确的指向性，后代选择器只需要加一个空格再加上需要影响的元素就可以了
## 并集选择器（兄弟选择器）

这个标题其实把两种不同的选择器写在了一起，分开看更清楚。

### 并集选择器

用逗号 `,` 把多个选择器并列起来，让它们共用同一套样式：

```html
<style>
	h1, h2, p {
		color: red;
	}
</style>
```

上面表示 `h1`、`h2`、`p` 这三种元素都会应用红色。

### 兄弟选择器

用于选中同一父元素下、与目标元素同级的「兄弟元素」，有两种写法：

- `+` 相邻兄弟选择器：只选中**紧挨着**的后一个兄弟。
- `~` 通用兄弟选择器：选中后面**所有**同级兄弟。

```html
<style>
	h2 + p { color: red; }   /* 只影响紧跟 h2 的那一个 p */
	h2 ~ p { color: blue; }  /* 影响 h2 后面所有的 p */
</style>

<h2>标题</h2>
<p>这段是相邻兄弟，会变红</p>
<p>这段是后续兄弟，只受 ~ 影响</p>
```
## 伪类选择器

伪类以冒号 `:` 开头，用于给元素在**特定状态**下应用样式，比如鼠标悬停、被点击、获得焦点等。

常见伪类：

| 伪类 | 作用 |
| --- | --- |
| `:hover` | 鼠标悬停在元素上时 |
| `:active` | 元素被按下（激活）时 |
| `:focus` | 元素获得焦点时（如输入框被选中） |
| `:visited` | 链接已被访问过时 |
| `:first-child` | 元素是其父元素的第一个子元素时 |
| `:nth-child(n)` | 元素是其父元素的第 n 个子元素时 |

e.g.
```html
<style>
	a:hover {
		color: red;
	}
</style>

<a href="#">把鼠标放上来</a>
```

注意：伪类要**紧贴**在选择器后面，中间不能有空格。`a:hover` 表示「悬停时的 `a`」，而 `a :hover`（多了空格）表示 `a` 的后代元素，意思完全不同。

**小抄**：`h3.classname` 快速写出 class 的名字，`h3#idname` 快速写出 id。
