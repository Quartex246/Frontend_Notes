## 复合属性

复合属性指的是**一种可以一次性设置多个相关属性值的简写属性**。

例如 font 属性就是一个复合属性。在之前的练习中我们在设置字体颜色或字体大小时常常使用具体的属性，例如 font-size、font-family 等。但是 font 属性包含了这些子属性。如果我在它的后面直接加入属性值，也会生效：

```css
/* 分开写 */
p {
	font-style: italic;
	font-weight: bold;
	font-size: 16px;
	line-height: 1.5;
	font-family: "Microsoft YaHei", sans-serif;
}

/* 用复合属性写，效果完全一样 */
p {
	font: italic bold 16px/1.5 "Microsoft YaHei", sans-serif;
}
```

复合属性有顺序要求。以 font 为例，属性值必须按照下面的顺序书写：

**font-style → font-variant → font-weight → font-size/line-height → font-family**

其中 font-size 和 font-family 是**必填项**，而且 font-family 必须放在最后；line-height 用斜杠 `/` 跟在 font-size 后面。

注意：复合属性会把没写出来的子属性重置为默认值。比如只写 `font: 16px sans-serif;`，那么字体粗细、斜体等都会被重置成 normal，而不是保留之前单独设置的值。

## 行高 line-height

调节行间距，适用于长文本。

```css
p {
	line-height: 1.5;    /* 无单位数字：字号的 1.5 倍，最常用 */
	line-height: 24px;   /* 固定像素值 */
	line-height: 150%;   /* 百分比：同样相对字号计算 */
}
```

- 用**无单位数字**最好：子元素会继承这个数字，再根据自己的 font-size 重新计算行高；而 px 和百分比在继承时直接继承算好的值，遇到字号不同的子元素就会不协调。
- 小技巧：把 line-height 设成和 height 一样高，可以让单行文字在容器内垂直居中。

## 宽高 width / height

调节宽度和高度，适用于块元素和行内块元素。关于这两种元素参考 HTML 章节的块元素与行内元素。

```css
.box {
	width: 200px;
	height: 100px;
}
```

值得一提的是，行内元素不适用这个属性，其长宽高取决于该元素内所包含的内容。

常用单位：

| 单位          | 含义                           |
| ----------- | ---------------------------- |
| `px`        | 像素，固定大小                      |
| `%`         | 相对于父元素宽度（高度）的百分比             |
| `vw` / `vh` | 视口宽度（高度）的 1%，`100vw` 就是整个窗口宽 |
| `auto`      | 默认值，由浏览器根据内容计算               |

还有 `min-width` / `max-width` / `min-height` / `max-height` 用来限制宽高的范围，常见用途是配合 `width: 100%` 做响应式布局：

```css
img {
	width: 100%;
	max-width: 600px;   /* 最宽不超过 600px，窗口再大也不继续放大 */
}
```

注意：默认情况下 width/height 设置的是**内容区**的大小，加上 padding 和 border 后元素实际占用的空间会更大，详见下一章盒子模型。

## display 属性

display 属性可以将某种元素转换为特定的元素。例如作为块元素的 div，可以通过添加 display 属性将其变为行内元素或者行内块元素。

常用取值：

| 取值             | 效果                                              |
| -------------- | ----------------------------------------------- |
| `block`        | 块元素：独占一行，可以设置宽高                                 |
| `inline`       | 行内元素：不独占一行，宽高由内容决定                              |
| `inline-block` | 行内块元素：不独占一行，但可以设置宽高                             |
| `none`         | 隐藏元素，并且**不占据空间**（`visibility: hidden` 则会隐藏但仍占位） |

e.g.

```html
<style>
	div {
		display: inline-block;
		width: 100px;
		height: 100px;
		background-color: lightblue;
	}
</style>

<div>1</div>
<div>2</div>
<div>3</div>
```

三个原本各占一行的 div，现在会排在同一个水平行里，并且依然可以设置宽高。

## 常用属性速查

| 属性 | 作用 | 示例 |
| --- | --- | --- |
| `color` | 文字颜色 | `color: red;` |
| `background-color` | 背景颜色 | `background-color: #f5f5f5;` |
| `background-image` | 背景图片 | `background-image: url(./bg.png);` |
| `font-size` | 字号 | `font-size: 16px;` |
| `font-family` | 字体 | `font-family: "Microsoft YaHei", sans-serif;` |
| `font-weight` | 字重（粗细） | `font-weight: bold;` 或 `700` |
| `font-style` | 是否斜体 | `font-style: italic;` |
| `text-align` | 文本水平对齐 | `text-align: center;` |
| `text-decoration` | 文本装饰线 | `text-decoration: underline;` |
| `text-indent` | 首行缩进 | `text-indent: 2em;` |
| `border` | 边框（复合属性） | `border: 1px solid #333;` |
| `border-radius` | 圆角 | `border-radius: 8px;` |
| `opacity` | 透明度，0 ～ 1 | `opacity: 0.5;` |

border、padding、margin 的具体用法见下一章盒子模型。
