上一章的浮动适合调整元素位置，但想精确控制某个元素落在哪里，用浮动会比较麻烦；而定位可以把元素放到精确的位置，却又不适合承担整体布局——两者各有所长。

## 定位方式

`position` 属性用来设置元素的定位方式，常用取值如下：

| 取值 | 参照物 | 是否脱离文档流 | 说明 |
| --- | --- | --- | --- |
| `static` | 无 | 否 | 默认值，元素按标准流排列，偏移属性无效 |
| `relative` | 自身原来的位置 | 否 | 相对定位，偏移后原位置仍然占着 |
| `absolute` | 最近的已定位祖先元素 | 是 | 绝对定位，找不到祖先时相对初始包含块 |
| `fixed` | 浏览器视口 | 是 | 固定定位，不随页面滚动 |
| `sticky` | 最近的滚动容器 | 否 | 粘性定位，到达阈值后“粘住” |

补充几点：

- `position: static` 是默认值，此时 `top`、`right`、`bottom`、`left`（以及它们的简写 `inset`）都不起作用。
- 除 `static` 外，其余四种都算“已定位元素”，可以作为绝对定位子元素的参照物。
- 偏移属性中，`top` 向下为正、`bottom` 向上为正、`left` 向右为正、`right` 向左为正。

```css
.box {
  position: relative;
  top: 20px;   /* 向下偏移 20px */
  left: 30px;  /* 向右偏移 30px */
}
```

## 相对定位

定义：相对于元素自己在文档流中的**正常位置**进行偏移，不脱离文档流。

```css
.box-relative {
  width: 100px;
  height: 100px;
  background-color: pink;
  position: relative;
  top: 20px;
  left: 30px;
}
```

可以看到，`.box-relative` 应用了相对定位，再配合 `top`、`right`、`bottom`、`left` 就能让它相对原来的位置偏移。注意只写 `position: relative` 而不写偏移量，元素是看不出变化的。

相对偏移**不会脱离文档流**。具体表现为：如果上下放了两个元素，在移动相对定位元素之后，它原来的位置仍然被占着，下面的元素不会上浮补位。也就是说，虽然视觉上它的位置变了，但本质上那个元素真正的位置还在那里。

```html
<div class="box1">
  <div class="box-normal"></div>
  <div class="box-relative"></div>
  <div class="box-normal"></div>
</div>
```

相对定位常用于：

- 微调元素位置；
- 给绝对定位的子元素当参照物，也就是常说的“子绝父相”；
- 配合 `z-index` 调整局部层级。

## 绝对定位

定义：相对于其**最近的已定位祖先元素**进行定位，脱离文档流；如果一直找不到已定位祖先，就相对初始包含块（可以简单理解为页面/视口）定位。

```css
.father {
  position: relative;  /* 给子元素提供定位参照 */
  width: 300px;
  height: 200px;
  background-color: #e8f4ff;
}

.son {
  position: absolute;
  top: 20px;
  right: 20px;
  width: 80px;
  height: 80px;
  background-color: pink;
}
```

和相对定位的写法差不多，主要区别是把 `position: relative` 换成 `position: absolute`。不过绝对定位的元素会**脱离文档流**，所以如果还出现上面的例子，下面的元素就会上浮补全空位。

绝对定位常见的用法是“子绝父相”：父元素设置 `position: relative`，子元素设置 `position: absolute`，这样父元素不脱标、子元素又能在父元素内部精确摆放。

如果想让绝对定位元素水平垂直居中，可以这样写：

```css
.son {
  position: absolute;
  top: 50%;
  left: 50%;
  transform: translate(-50%, -50%); /* 用自身宽高往回拉一半 */
}
```

## 固定定位

定义：相对于浏览器窗口定位，脱离文档流，并且固定在屏幕上的某个位置，不跟着滚动条移动。此时 `position` 的值为 `fixed`。

```css
.back-to-top {
  position: fixed;
  right: 24px;
  bottom: 24px;
}
```

很多网页的“返回顶部”按钮就是固定在一个地方，不会随着滚动进度条改变位置；固定导航栏、悬浮客服、弹窗遮罩也常用固定定位。

需要注意：如果固定定位元素的某个祖先设置了 `transform`、`filter` 或 `perspective`，这个祖先会生成新的包含块，`fixed` 就可能不再相对视口定位，而是相对该祖先定位。

## 粘性定位（补充）

`position: sticky` 可以理解为“相对定位 + 固定定位”：在滚动到指定阈值之前，它像相对定位一样待在文档流里；到达阈值后，它像固定定位一样“粘”住，但只在父容器的范围内生效。

```css
.sticky-title {
  position: sticky;
  top: 0; /* 距离滚动容器顶部 0px 时开始粘住 */
}
```

使用粘性定位必须设置 `top`、`bottom`、`left`、`right` 中的至少一个阈值，否则它和普通相对定位没有区别。常见用途是吸顶导航、表格表头、文章目录等。

## 层级 z-index

多个定位元素重叠时，可以用 `z-index` 控制谁在上面：

```css
.mask {
  position: fixed;
  inset: 0;
  background: rgba(0, 0, 0, 0.4);
  z-index: 999;
}

.modal {
  position: fixed;
  top: 50%;
  left: 50%;
  transform: translate(-50%, -50%);
  z-index: 1000; /* 比遮罩大，显示在遮罩上方 */
}
```

- `z-index` 默认是 `auto`，数值越大越靠上；
- 它只对定位元素（以及 Flex/Grid 子项）生效，给 `static` 元素设置通常没用；
- 数值相同时，HTML 中靠后的元素显示在上面；
- 父元素形成层叠上下文时，子元素的 `z-index` 只在父级内部比较，不能直接越过父级去和外面的元素比。

## 定位元素的特点

- `absolute` 和 `fixed` 会脱离文档流，不再撑开父元素，父元素可能因此高度坍塌（和浮动脱标的情况类似，见 [[5.浮动#坍塌和溢出]]）。
- 元素一旦绝对/固定定位，`display` 计算值会变成 `block`，所以 `span`、`a` 这类行内元素也能设置宽高。
- 绝对/固定定位元素的宽高默认由内容决定，不会自动占满父元素。
- `relative` 不脱标，原位置保留；`sticky` 在粘住前也不脱标。
- `top`、`right`、`bottom`、`left` 对 `position: static` 无效。
- 绝对定位的参照物是最近已定位祖先的 **padding box**；固定定位默认参照视口。
- 实际项目中整体布局优先用 Flex/Grid，定位更多用于局部精确控制、浮层、导航和弹窗。

## 四种定位对比

| 定位方式 | `position` 值 | 参照物 | 是否脱标 | 是否随页面滚动 | 常见用途 |
| --- | --- | --- | --- | --- | --- |
| 静态定位 | `static` | 无 | 否 | 是 | 默认排版 |
| 相对定位 | `relative` | 自身原位置 | 否 | 是 | 微调、给绝对定位当参照 |
| 绝对定位 | `absolute` | 最近的已定位祖先 | 是 | 是 | 角标、下拉菜单、局部精确定位 |
| 固定定位 | `fixed` | 浏览器视口 | 是 | 否 | 固定导航、返回顶部、弹窗遮罩 |
| 粘性定位 | `sticky` | 滚动容器 + 阈值 | 否 | 粘住前是，粘住后否 | 吸顶标题、表格表头 |

## 总结

- `position` 用来设置定位方式，常用值有 `relative`、`absolute`、`fixed`、`sticky`；
- `relative` 相对自身原位置偏移，不脱标，原位置保留；
- `absolute` 相对最近的已定位祖先偏移，脱标，常配合“子绝父相”使用；
- `fixed` 相对浏览器视口定位，脱标，不随页面滚动；
- `sticky` 在到达阈值前像相对定位，之后在父容器范围内“粘住”；
- 定位元素重叠时用 `z-index` 控制层级，数值越大越靠上。
