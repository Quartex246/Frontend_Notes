## 定义

如果说html定义**结构内容**，那么css就是定义**网页样式和外观**

css可以指定颜色字体间距背景边框

## 语法

组成：**选择器，属性，属性值**

多个属性可以组合在一个选择器里

```css
选择器{
	属性1: 属性值1;
	属性2: 属性值2;
}
```

注意：
- 选择器声明可以写无数条属性
- 每个属性都需要以分号结尾
- 生命中所有的属性和属性值都是以键值对这种形式出现的

写完了属性，就要将这一块放到`<style>`标签内。导入有三种方式，这是下文的内容

e.g.
```css
p {
	color: blue;
	font-size: 16px;
}
```

上面的例子是一个应用到p标签的样式（如果你忘了什么是p，查看标签），接下来在body段内写的所有的p都会应用所给的样式

## 三种导入方式

### 内联样式

Inline styles，指的是将外观直接嵌入标签中
e.g.
```html
<h1 style = "color = red; font-size = 16px">

	this is a header
	
</h1>
```
注意：
- 即使在标签内，也需要遵循css语法格式
### 内部样式表

Internal stylesheet，将所有需要应用的样式保存在`<style>`标签内，会自动应用到body

```html
<style>
	h3 {
		color: ultraviolet;
		font-size: 256px;
	}
</style>

<body>
	<h3> this is a header </h3>
</body>
```
### 外部样式表

External stylesheet，和内部样式表格式差不多，只不过是在一个外部的css文件中写入配置，并在html页面中导入

优势是可以做一个模板，然后在多个网页都能应用

需要在HTML文件`<head>`部分写入导入语句
```html
<link rel = "stylesheet" href = "./css/style.css">
```

### 优先级

导入优先级：**内联样式 > 内部样式表 > 外部样式表**

优先级越高会覆盖上一级
