在之前的学习中，元素永远都会像一个文档那样从上到下写下内容。而且内容很简陋，撑死改一下颜色。这就要用到浮动，其作用是元素脱离文档流，让元素可以根据开发者的想法移动到任意位置

浮动和行内块的区别
前者贴在一起，不会有缝隙

浮动相对父元素浮动，

## 三大特性

- **脱标**
	脱离标准流，可以移动到指定位置
	或者说，相比于其他元素，脱标的元素将会浮在其他元素之上，后面的元素将会认为它不存在

- **一行显示，顶部对齐**
	若多个盒子同时设置，按照属性值一行显示，并顶端对其排列
	也就是说，他会像一个字一样一直往后排

- **有行内块特性**
	这个自己去翻那片行内块的文章

## 举例子和解释说明

接下来我们将看一段实际的代码
```html
  <style>
  
    .father {
      background-color: aquamarine;
      height: 150px;
      border: 3px solid brown;
    }
    
    .left-son {
      width: 100px;
      height: 100px;
      background-color: yellowgreen;
      float: left;
    }
    
    .right-son {
      width: 100px;
      height: 100px;
      background-color: yellow;
      float: right;
    }
    
  </style>
</head>

<body>
  <div class="father">
    <div class="left-son">左浮动</div>
    <div class="right-son">右浮动</div>
  </div>
  
</body>
</html>
```
我们可以看到左浮动和右浮动元素全部都是归于一个父元素的
