
HTML的基础，所有元素都是标签所定义的

## 格式

```html
<p> </p>
```

这是个双标签，成对出现。用于含有内容的元素
还有没有尾巴的单标签，用于没内容的

![[html_structure.png]]

**层级结构说明：**

- **根节点**：`<html>` 是整个文档的根元素。
    
- **直接子节点**：`<html>` 下包含两个主要部分 `<head>` 和 `<body>`。
    
- **head 分支**：包含文档的元信息（如 `<title>`、`<meta>`）以及外部资源引用（`<link>`、`<script>`），并包含相应的注释。
    
- **body 分支**：包含页面显示的实际内容，如标题 `<h1>`、段落 `<p>` 和超链接 `<a>`，以及对应的注释。

## 常用文本标签

### 段落

`<p>` 标签定义段落，是页面中最基本的内容单元。浏览器会自动在段落前后添加空行。

```html
<p>这是第一个段落。</p>
<p>这是第二个段落。</p>
```

**注意**：不要用连续的空 `<p>` 来制造空白间距，应通过 CSS 的 `margin` / `padding` 控制。

### 标题

`<h1>` 到 `<h6>` 用于定义标题，`<h1>` 级别最高（字号最大），`<h6>` 级别最低。

```html
<h1>一级标题</h1>
<h2>二级标题</h2>
<h3>三级标题</h3>
<h4>四级标题</h4>
<h5>五级标题</h5>
<h6>六级标题</h6>
```

**注意**：标题用于表达文档结构，而非单纯控制字号；一个页面通常只保留一个 `<h1>`，用作页面主标题。

### 列表

#### 有序列表

使用 `<ol>`（ordered list）包裹，每一项用 `<li>`（list item）表示，适合有先后顺序的内容。

```html
<ol>
  <li>第一步</li>
  <li>第二步</li>
  <li>第三步</li>
</ol>
```

`type` 属性可改变序号样式（`1`、`A`、`a`、`I`、`i`），`start` 属性用于指定起始序号。

#### 无序列表

使用 `<ul>`（unordered list）包裹，其余与有序列表相同，适合无顺序要求的内容。

```html
<ul>
  <li>苹果</li>
  <li>香蕉</li>
  <li>橙子</li>
</ul>
```

#### 定义列表

使用 `<dl>`（definition list），术语用 `<dt>`（definition term），解释用 `<dd>`（definition description）。

```html
<dl>
  <dt>HTML</dt>
  <dd>超文本标记语言，负责页面的结构。</dd>
</dl>
```

**嵌套**：`<li>` 内可再放置 `<ul>` 或 `<ol>`，实现多级列表。

### 表格

表格由 `<table>` 定义，内部由行 `<tr>`、表头 `<th>` 和单元格 `<td>` 组成。

```html
<table>
  <caption>学生成绩表</caption>
  <thead>
    <tr>
      <th>姓名</th>
      <th>成绩</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>张三</td>
      <td>90</td>
    </tr>
    <tr>
      <td>李四</td>
      <td>85</td>
    </tr>
  </tbody>
</table>
```

**标签说明**：

- `<caption>`：表格标题
- `<thead>` / `<tbody>` / `<tfoot>`：表头 / 主体 / 表尾，用于结构分组
- `<tr>`：表格行（table row）
- `<th>`：表头单元格（table header），默认加粗居中
- `<td>`：数据单元格（table data）

`colspan` / `rowspan` 属性可分别用于合并列 / 行。

### 超链接引用

`<a>`（anchor，锚）标签用于创建超链接，通过 `href` 属性指向跳转目标。

```html
<a href="https://www.example.com">访问示例网站</a>
```

**四种跳转方式**：

```html
<!-- 1. 外部链接：跳转到站外地址（绝对 URL） -->
<a href="https://www.example.com">外部链接</a>

<!-- 2. 内部链接：跳转到本站其他页面（相对路径） -->
<a href="./about.html">内部链接</a>

<!-- 3. 锚点链接：跳转到当前页面指定 id 的位置（页面中需存在 id="top" 的元素） -->
<a href="#top">返回顶部</a>

<!-- 4. 邮件链接：唤起邮件客户端 -->
<a href="mailto:hi@example.com">给我发邮件</a>
```

**其他要点**：

- `<a>` 是双标签，内容既可以是文字，也可以是图片等元素。
- 加 `target="_blank"` 可让链接在新标签页打开。
- `href`、`target` 都属于 `<a>` 的属性，详见 [[HTML/属性.md|属性]] 的「引用标签属性」。

### 图片

使用单标签 `<img>` 引入图片，格式：

```html
<img src="cat.png" alt="一只猫" width="200" height="150" title="悬浮提示">
```

- `src`：图片路径（必需）
- `alt`：替换文本，图片加载失败时显示，也用于无障碍阅读（必需）
- `width` / `height`：宽高
- `title`：鼠标悬停时的提示文字

更多说明见 [[HTML/属性.md|属性]] 的「图片标签属性」。
