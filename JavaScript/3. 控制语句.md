控制语句用来控制代码的执行顺序。默认情况下，代码从上往下依次执行；而分支语句会根据条件决定“走哪一条路”。JavaScript 中最常用的分支就是 `if`、`else if` 和 `else`。

## if 单分支

语法：

```js
if (条件) {
  // 条件成立时执行
}
```

`if` 后面的括号里写条件，条件的结果会被转换成布尔值：为 `true` 时执行大括号里的代码，为 `false` 时直接跳过。

```js
let age = 18;

if (age >= 18) {
  console.log("已成年");
}
```

如果只有一行代码，也可以不写大括号：

```js
if (age >= 18) console.log("已成年");
```

但实际开发中建议**总是写大括号**，这样以后往里面加代码时不容易出错。

## if...else 双分支

需要“条件成立做一件事，不成立做另一件事”时，用 `else`：

```js
if (条件) {
  // 条件成立
} else {
  // 条件不成立
}
```

例子：

```js
let score = 58;

if (score >= 60) {
  console.log("及格");
} else {
  console.log("不及格");
}
```

`if` 和 `else` 必定会执行其中一个分支，不会两个都执行，也不会都不执行。

## if...else if...else 多分支

当情况超过两种时，可以继续用 `else if` 往下判断：

```js
if (条件1) {
  // 条件1成立
} else if (条件2) {
  // 条件1不成立，且条件2成立
} else if (条件3) {
  // 前面都不成立，且条件3成立
} else {
  // 全部不成立
}
```

例子：根据分数划分等级。

```js
let score = 85;

if (score >= 90) {
  console.log("优秀");
} else if (score >= 75) {
  console.log("良好");
} else if (score >= 60) {
  console.log("及格");
} else {
  console.log("不及格");
}
// 输出：良好
```

执行规则是**从上往下依次判断，遇到第一个成立的条件就进入对应分支，后面的条件不再判断**。

所以条件的顺序非常重要。如果把上面的顺序改成：

```js
if (score >= 60) {
  console.log("及格");
} else if (score >= 90) {
  console.log("优秀");
}
```

那么 85 分会先命中 `score >= 60`，直接输出“及格”，`score >= 90` 根本没机会执行。写多分支时，通常把**范围更小、更严格的条件放在前面**。

`else` 不是必须的。如果不需要“以上都不成立”的兜底处理，可以不写；但写一个 `else` 往往能让逻辑更完整。

## 条件里的真假值

`if` 括号里不一定非要写比较表达式，任何值都会被转换成布尔值。

在 JavaScript 中，下面这些值会被当作 `false`（称为 falsy 值）：

- `false`
- `0` 和 `-0`
- `0n`（BigInt 的 0）
- `""`（空字符串）
- `null`
- `undefined`
- `NaN`

除了这些，其他值都会被当作 `true`，包括：

```js
if ("0") console.log("非空字符串是真值"); // 会执行
if (" ") console.log("空格字符串也是真值"); // 会执行
if ([]) console.log("空数组是真值");       // 会执行
if ({}) console.log("空对象是真值");       // 会执行
```

所以判断一个变量是否有值时，直接写变量名也可以：

```js
let name = "";

if (name) {
  console.log("有名字");
} else {
  console.log("名字为空");
}
// 输出：名字为空
```

不过，如果你明确想判断“是否等于某个值”，还是写清楚比较表达式更好，避免把 `0`、空字符串这类正常数据误判成“没有值”。

## 比较运算符和逻辑运算符

`if` 里的条件通常由比较运算符组成：

| 运算符 | 含义 | 示例 |
| --- | --- | --- |
| `>` | 大于 | `score > 60` |
| `<` | 小于 | `score < 60` |
| `>=` | 大于等于 | `score >= 60` |
| `<=` | 小于等于 | `score <= 60` |
| `==` | 相等（会做类型转换） | `1 == "1"` 为 `true` |
| `===` | 严格相等（类型和值都相同） | `1 === "1"` 为 `false` |
| `!=` | 不相等（会做类型转换） | `1 != "1"` 为 `false` |
| `!==` | 严格不相等 | `1 !== "1"` 为 `true` |

推荐优先使用 `===` 和 `!==`。`==` 会先把两边转换成同一类型再比较，容易得到意想不到的结果，例如：

```js
console.log(0 == "");        // true
console.log(0 == "0");       // true
console.log(null == undefined); // true
console.log(NaN == NaN);     // false
```

多个条件可以用逻辑运算符组合：

- `&&`：并且，两边都为真才为真，例如 `age >= 18 && age <= 60`；
- `||`：或者，任意一边为真就为真，例如 `role === "admin" || role === "owner"`；
- `!`：取反，例如 `!isLogin`。

```js
let age = 25;
let hasTicket = true;

if (age >= 18 && hasTicket) {
  console.log("可以入场");
}
```

`&&` 和 `||` 还具有“短路”特性：`&&` 遇到第一个假值就停止，`||` 遇到第一个真值就停止。因此它们经常被用来做默认值：

```js
let username = inputName || "游客";
```

不过要注意，如果 `inputName` 是 `0` 或空字符串，也会被替换成“游客”。现代写法也可以用 `??`（空值合并），它只在 `null` 或 `undefined` 时才取后面的值：

```js
let username = inputName ?? "游客";
```

## 嵌套 if

`if` 里面还可以再写 `if`，用来处理更细的条件：

```js
let age = 20;
let isStudent = true;

if (age >= 18) {
  if (isStudent) {
    console.log("成年学生，可以购买学生票");
  } else {
    console.log("成年，购买成人票");
  }
} else {
  console.log("未成年，购买儿童票");
}
```

嵌套层级太深会让代码难以阅读，能合并的条件尽量合并，或者提前用 `return` 结束函数：

```js
function check(age, isStudent) {
  if (age < 18) return "儿童票";
  if (isStudent) return "学生票";
  return "成人票";
}
```

这种“提前返回”的写法比层层嵌套更清晰。

## 三元运算符（简写）

只有两种结果、逻辑比较简单时，可以用三元运算符代替 `if...else`：

```js
条件 ? 条件成立时的值 : 条件不成立时的值
```

例子：

```js
let score = 72;
let result = score >= 60 ? "及格" : "不及格";

console.log(result); // 及格
```

它适合用来赋值或拼接字符串，不适合塞入太复杂的逻辑。嵌套三元运算符可读性很差，不建议使用。

## 补充：switch

如果要判断的是“一个变量等于哪几个固定值”，用 `switch` 会比一长串 `else if` 更清晰：

```js
let day = 3;

switch (day) {
  case 1:
    console.log("星期一");
    break;
  case 2:
    console.log("星期二");
    break;
  case 3:
    console.log("星期三");
    break;
  default:
    console.log("其他");
}
```

注意：

- `switch` 用的是严格相等（`===`）比较；
- 每个 `case` 后面通常要写 `break`，否则会继续执行下一个 `case`（称为“穿透”，有时也会故意利用）；
- `default` 处理所有没有匹配到的情况。

## 常见错误

### 1. 把赋值 `=` 写成了比较

```js
let x = 0;

if (x = 5) {
  console.log("会执行");
}
```

`x = 5` 是赋值表达式，结果是被赋的值 `5`，转换成布尔值是 `true`，所以条件永远成立。应该写成：

```js
if (x === 5) {
  console.log("x 等于 5");
}
```

### 2. if 后面多了分号

```js
if (x > 0); {
  console.log("会执行");
}
```

`if (x > 0);` 后面的分号表示“条件成立时执行一个空语句”，下面的大括号就变成了普通代码块，无论条件真假都会执行。写 `if` 时不要在括号后面加分号。

### 3. 大括号省略导致 else 匹配错

```js
if (a)
  if (b)
    console.log("ab");
else
  console.log("?");
```

这里的 `else` 会和最近的、还没有匹配的 `if (b)` 配对，而不是 `if (a)`。这种情况最容易出错，建议始终写大括号：

```js
if (a) {
  if (b) {
    console.log("ab");
  }
} else {
  console.log("a 不成立");
}
```

### 4. 多分支顺序写反

前面提过，`else if` 从上往下判断，第一个成立的分支会“截胡”。范围判断要按从大到小或从小到大排好顺序，避免宽泛的条件挡住严格的条件。

### 5. 用 `==` 比较不同类型的值

```js
if ("10" > 9) {
  console.log("会执行");
}
```

两个不同类型的值比较时，JavaScript 会先做类型转换，`"10"` 被转成数字 `10`，所以结果是 `true`。如果数据来自输入框，记得先用 `Number()` 转成数字再比较。

## 小结

- `if`：条件成立时执行；
- `if...else`：二选一；
- `if...else if...else`：多选一，按顺序判断，第一个成立的分支生效；
- 条件会被转换成布尔值，`0`、`""`、`null`、`undefined`、`NaN` 等是假值；
- 比较优先用 `===` 和 `!==`，多条件用 `&&`、`||` 组合；
- 简单二选一可以用三元运算符，固定值多选一可以用 `switch`；
- 始终写大括号，注意条件顺序，不要把 `=` 当成 `===`。
