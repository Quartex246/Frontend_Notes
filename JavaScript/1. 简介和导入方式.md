JavaScript，总之就是可以让网页进行互动。本文章重点讲述如何导入

## 内联式

js放在script标签内，script标签可以放到body和head标签内

尽量放在body中。放在head中会降低页面响应速度

## 外联式

js放到单独的文件中，并在主文件中导入脚本

e.g.
```html
<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta http-equiv="X-UA-Compatible" content="IE=edge">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>JS 导入方式</title>

  <script>
    console.log('Hello, Head 标签的内联样式');  <--- 内联式
  </script>

  <script src="./js/myscript.js"></script>    <--- 外联式
</head>

<body>
  <h1>JavaScript 的导入方式</h1>
  <script>
    console.log('Hello, body标签的内联样式');
    alert("你好，内联样式弹窗");
  </script>
</body>

</html>
```

可以看到，内联式只需要在script标签内加入需要执行的操作就行，外联式需要在script标签内加上src作为脚本的源头。

示例代码中给出了两种交互，一种是console.log，将会在浏览器的控制台中显示调试信息，另一种alert是网页顶部会弹出相应的提示
