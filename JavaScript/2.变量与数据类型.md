## 变量

关键字
var：变量，全局作用域
let：也是变量，块级作用域
const：常量

e.g.

```js
if (true) {
  var a = 1;
  let b = 2;
}
console.log(a); // 1
console.log(b); // ReferenceError: b is not defined
```

看控制台就可以发现b的值没有显示，因为a是var定义的全局变量，哎反正就是public
