## 块元素（block）

块级元素通常用于组织和布局页面的主要结构和内容，例如段落、标题、列表、表格等。它们用于创建页面的主要部分，将内容分隔成逻辑块。

- 块级元素通常会从新行开始，并占据整行的宽度，因此它们会在页面上呈现为一块独立的内容块。

- 可以包含其他块级元素和行内元素。

- 常见的块级元素包括 `<div>`、`<p>`、`<h1>` 到 `<h6>`、`<ul>`、`<ol>`、`<li>`、`<table>`、`<form>` 等。

### `<div>`

`<div>`的作用是作为一个可以包含其他元素的块元素。没有语义，只有排版用

例如网页有个头部导航栏 `header`，脚注 `footer`，我们可以用 `div` 来将他们分成几块，而不是让他们都挤在 `body`

e.g.
```html
<div class = "header"> # 头注

	<a href = "#"> Table of headers </a>
	
</div>

<div class = "footer"> # 脚注

	<a href = "#"> Arknights players </a>
	
</div>
```

我认为可以理解为一个自然段，自然段里可以包含其他部分

## 行内元素（inline）

行内元素通常用于添加文本样式或为文本中的一部分应用样式。它们可以在文本中插入小的元素，例如超链接、强调文本等。

- 行内元素通常在同一行内呈现，不会独占一行。

- 它们只占据其内容所需的宽度，而不是整行的宽度。

- 行内元素不能包含块级元素，但可以包含其他行内元素。

- 常见的行内元素包括 `<span>`、`<a>`、`<strong>`、`<em>`、`<img>`、`<br>`、`<input>` 等。

个人认为两者的区别就是块元素是一大块，行内元素真的就是一行。甚至你需要`<br>`换行标识符才能让他换下一行而不是挤在同一行
