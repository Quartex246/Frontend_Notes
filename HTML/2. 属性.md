## 基础语法

```html
<开始标签 属性名 = “属性值”> 

	内容
	
<结尾标签>
```

e.g.
```html
<p id = "describe">
```

每个HTML标签可以有多个不同的属性
例：

```html
<!-- 一个标签可以同时拥有多个属性，用空格分隔 -->
<img src="cat.png" alt="一只猫" width="200" height="150">
```

属性名称不区分大小写，但属性的值区分
例：

```html
<!-- 属性名不区分大小写，下面几种写法完全等价 -->
<img src="cat.png">
<img SRC="cat.png">
<img Src="cat.png">

<!-- 但属性值区分大小写，note 与 Note 是两个不同的类 -->
<p class="note">A</p>
<p class="Note">B</p>
```

## 基础属性

有的属性只限于特定的元素使用，但以下属性基本上所有元素都能用

| 属性    | 描述             |
| ----- | -------------- |
| class | 为HTML定义一个或多个类名 |
| id    | 定义元素唯一的属性      |
| style | 规定元素行内样式       |
| title | 定义元素的额外说明信息（鼠标悬停时提示） |
| lang  | 定义元素内容的语言      |
| data-* | 自定义数据属性，用于在元素上存储私有数据 |

### class和id的区别

两者都用于给元素“贴标签”，方便 CSS 选择和 JavaScript 定位，但分工不同。

| 对比项  | id                  | class                  |
| ---- | ------------------- | ---------------------- |
| 唯一性  | 同一页面内必须唯一           | 可以重复使用                 |
| 数量   | 一个元素只能有一个 id        | 一个元素可以有多个 class（用空格分隔） |
| 选择器  | `#name`             | `.name`                |
| 优先级  | 高                   | 低（低于 id 选择器）           |
| 常见用途 | 唯一标识、页面锚点、JS 精确定位   | 批量归类、复用样式              |

**示例**：

```html
<!-- 同一个 class 可以被多个元素复用 -->
<p class="note">第一条</p>
<p class="note">第二条</p>

<!-- 一个元素可以同时拥有多个 class -->
<p class="note highlight">第三条</p>

<!-- id 在同一页面内只应出现一次 -->
<div id="header">页面头部</div>
```

**口诀**：id 是身份证，一人一号，不可重复；class 是标签，能贴多个，也能贴给很多人。


### 补充

#### class和id是CSS的属性吗

答：**不是**

后面学习的CSS对于HTML样式有着重要的作用，我看着class是一种可以用在各种标签的模板格式所以想着他会不会也是CSS的内容

但AI告诉我不是这样的。他们**都是铁血HTML属性，但是他们支持从CSS引入格式**，相当于一个钩子

#### id不影响格式？

一个常见误区是「id 只是标识、不影响格式」。实际上 `id` 同样是合法的 CSS 选择器，而且优先级比 `class` 更高。

```html
<p id="title" class="note">一段文字</p>
```

```css
.note  { color: gray; }   /* class 选择器 */
#title { color: red;  }   /* id 选择器 —— 优先级更高，文字最终为红色 */
```

两者都命中同一个元素时，**id 会赢**。所以准确的说法是：

- **class 和 id 都是 HTML 全局属性**，CSS 与 JS 都能用它们来选中元素，它们不属于某一方的私有资源；
- **class 是「分类」**：可重复使用，用于批量套用样式，CSS 里用 `.name` 选中，优先级较低；
- **id 是「身份」**：同一页面内唯一，常用作页面锚点和 JS 精确定位，CSS 里用 `#name` 选中，**优先级高于 class**。

## 额外的标签属性

反正网课有说，顺手补上。

#### 引用标签属性

`<a>` 标签定义超链接，`href`（hypertext reference）属性指向链接目标，共有四种常见跳转方式：

```html
<!-- 1. 外部链接：跳转到站外地址（绝对 URL） -->
<a href="https://www.example.com">外部链接</a>

<!-- 2. 内部链接：跳转到本站其他页面（相对路径） -->
<a href="./about.html">内部链接</a>

<!-- 3. 锚点链接：跳转到当前页面指定 id 的位置 -->
<a href="#top">返回顶部</a>

<!-- 4. 邮件链接：唤起邮件客户端 -->
<a href="mailto:hi@example.com">给我发邮件</a>
```

补充：加上 `target="_blank"` 可以让链接在新标签页打开。

全世界的人类都应该用`_blank`来打开新的标签页

#### 图片标签属性

`<img>` 是单标签，靠属性来描述图片。

```html
<img src="cat.png" alt="一只猫" width="200" height="150" title="悬浮提示">
```

| 属性 | 作用 |
| --- | --- |
| `src` | 图片路径（必需） |
| `alt` | 替换文本，图片加载失败时显示，也用于无障碍阅读（必需） |
| `width` / `height` | 图片宽高 |
| `title` | 鼠标悬停时的提示文字 |

值得一提的是，height和width只需要调一个数值就可以等比例缩放
