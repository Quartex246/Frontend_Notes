表单（Form）是网站中的搜索框，就这样

表单的格式如下

```html
<form>

	<input type = "text" placeholder = "enter text">
	<input type = "text" value = "enter text">
	
</form>
```

表单是一种**块元素**，你可以在这个表单里面放入多种不同类型的输入 `input`
## `input` 常用属性 

### `type` 

规定 `input` 元素类型。`input` 中有十余种类型，`type` 就是来选定类型的

下面两个属性与 `text` 类型强关联

#### `placeholder`

占位符。在 `placeholder` 中出现的内容，会在未选中表单输入文字时在表单中显示，点击之后就会消失

#### `value`

和 `placeholder` 很像，只不过点击之后不会消失

### `radio`

描述为圆形的选择，是 `type` 的一种类型。

格式如下
```html
<input type = "radio" name = "gender"> male
<input type = "radio" name = "gender"> female
<input type = "radio" name = "gender"> others
```

实际效果如下所示

---
<input type = "radio" name = "gender"> male
<input type = "radio" name = "gender"> female
<input type = "radio" name = "gender"> others

---

值得一提的是，在没有 `name` 这个属性时，`radio` **可以选择多个选项**，如果给这些相关的选项都设置一个 `name`，那么就可以单选了。我个人的理解为用 `name` 属性来设置一个种类


### `checkbox`

描述为方形的选择，也是一种 `type` 类型

`checkbox` 设计就是为了多选的，所以即使给他 `name` 也可以多选

格式如下
```html
<input type = "checkbox" name = "hobby"> reading
<input type = "checkbox" name = "hobby"> music
<input type = "checkbox" name = "hobby"> gaming
```

实际效果如下所示

---

<input type = "checkbox" name = "hobby"> reading
<input type = "checkbox" name = "hobby"> music
<input type = "checkbox" name = "hobby"> gaming

---
### `submit`

提交，写了就有一个神奇小按钮

```html
<input type = "submit" value = "提交">
```

## 表单属性

### `action`

提交之后，需要建一个新的带有 `action` 属性的表单，`action` 属性内需要写上后端提供的用来交换数据的 URL

格式如下

```html
<form action = "www.thisisawebsite.com">

	<input type = "text" name = "username">
	<input type = "submit" value = "提交">
	
</form>
```

### `for`

`for` 属性用于把 `<label>` 和它描述的表单控件绑定在一起，它的值应当写成目标控件的 `id`：

```html
<!-- for 的值必须和目标控件的 id 完全一致 -->
<label for = "user"> 用户名: </label>
<input type = "text" id = "user">
```

- **作用**：绑定之后，点击 `<label>` 中的文字就能自动聚焦 / 选中对应的控件，屏幕阅读器也能识别「文字—控件」的对应关系。
- **注意**：`for` 的值要和控件的 `id` 一模一样，写错就关联不上；因为 `id` 在同一页面内唯一，所以一个 `id` 也只能被一个 `for` 指向。

## 关联标签

### `<span>`
假设我想在我的表单前面加入一个你需要输入的内容，那么就需要使用 `span` 标签来添加描述的内容

e.g.

```html
<form>
	<span> username: </span>
	<input type = "text" placeholder = "enter text">
	
	<span> password: </span>
	<input type = "text" value = "enter text">
	
</form>
```
### `<label>`

重点其实应该是这个。

`label` 的特殊之处在于它可以和表单控件关联，点击说明文字就能选中对应的控件。关联方式有两种：

1. 用 `for` 属性指向控件的 `id`：

```html
<label for = "user"> 用户名: </label>
<input type = "text" id = "user">
```

2. 直接把控件包在 `label` 里面：

```html
<label> 用户名: <input type = "text"> </label>
```

`for` 的值必须和对应控件的 `id` 一致，两者才能关联起来。

### `<span>` 与 `<label>` 的对比

两者都常出现在表单的输入框旁边，但职责完全不同：

| 对比项 | `<span>` | `<label>` |
| --- | --- | --- |
| 语义 | 无语义的通用行内容器 | 表单控件的说明文字 |
| 与控件的关联 | 无，只是一段普通文字 | 有，和控件绑定在一起 |
| 关联方式 | 无 | `for` 指向控件 `id`，或直接包裹控件 |
| 点击效果 | 点击没有任何反应 | 点击即聚焦 / 选中对应控件 |
| 无障碍 | 不提供 | 屏幕阅读器能识别「文字—控件」关系 |
| 典型用途 | 给一段文字加样式或分组 | 给输入框加可点击的标签 |

**对比示例**：

```html
<form>
	<!-- span：只是普通描述文字，点击它不会选中输入框 -->
	<span> username: </span>
	<input type = "text" id = "user">

	<!-- label：点击文字就会聚焦对应的输入框 -->
	<label for = "pwd"> password: </label>
	<input type = "text" id = "pwd">
</form>
```

**一句话**：`span` 是「说明牌」，只负责显示文字；`label` 是「开关」，点一下就能操作对应的输入框。所以做表单字段说明时优先用 `<label>`，`<span>` 更适合纯装饰性的文字。
